# Weather Helper — agent notes

Single-purpose Capacitor Android app. Full architecture, scoring tables, and
build docs live in [README.md](README.md) — read that for feature/scoring
details instead of re-deriving them. This file is just the stuff a coding
agent needs to move fast and avoid mistakes.

## Source of truth vs generated

- Edit `js/`, `css/`, `index.html`, `native-bridge.js` — these are the real source.
- `dist/` is generated by `npm run build` (git-ignored). **Never hand-edit `dist/`.**
- `artifacts/*.apk` is generated, git-ignored. Never hand-edit.
- `android/` is a committed Capacitor-generated Gradle project, but it has
  manual edits on top (manifest permission strips, signing config). Don't
  regenerate it blindly (`cap add android`) — use `npm run android:sync` to
  refresh it, and check `git diff` in `android/` before committing sync results.

## Commands

```bash
npm test              # node --test over tests/*.test.js — fast, no build needed
npm run build          # js/css/html -> dist/, then verifies no remote script/link/img refs
npm run android:sync   # build + npx cap sync android
npm run android:debug  # sync + gradle assembleDebug -> artifacts apk (via scripts/build-android.mjs)
npm run android:release
```

No lint/typecheck script is configured (plain vanilla JS, `type: module`, no bundler).
Always run `npm test` after touching `js/core/*` — that's where the scoring/eval logic lives and has the heaviest test coverage.

## Code map (`js/core/` is pure logic, everything else is I/O/UI)

| File | Responsibility |
|---|---|
| `js/core/weather_api.js` | MET Norway fetch, complete→compact fallback |
| `js/core/scoring.js` | Per-factor scoring tables (temp/wind/cloud/precip/humidity) |
| `js/core/evaluation.js` | Combines scores into hourly/day evaluations, activity profiles |
| `js/core/locations.js` | Static location/region definitions |
| `js/core/timezone.js` | Europe/Madrid local-time conversion helpers |
| `js/core/daily_summary.js` | Builds the daily notification recommendation text |
| `js/core/models.js` | Shared data shapes |
| `js/core/presentation.js` | Formatting for display |
| `js/app.js` | Foreground UI orchestrator |
| `js/notifications.js` | Settings screen + notification scheduling |
| `js/background-task.js` | `@capacitor/background-runner` headless daily entry point |
| `native-bridge.js` | Wraps Capacitor App/LocalNotifications/Preferences plugins |

`js/app.js` and `js/background-task.js` both consume `js/core/*` — when
changing scoring/evaluation behavior, check both call sites, and check the
matching test in `tests/`.

## Non-obvious constraints (don't "fix" these)

- `CapacitorHttp` is enabled so `fetch()` routes through native HTTP — this
  is required so a custom `User-Agent` reaches MET Norway (their API terms
  require it) from both the foreground app and the background task.
- The Android manifest explicitly strips location permissions
  (`tools:node="remove"`) pulled in by `@capacitor/background-runner`'s own
  manifest fragment — this app never does geolocation, on purpose.
- `version.json` (`versionName`/`versionCode`) is the single source Gradle
  reads for versioning. `versionCode` must strictly increase for any release
  build — bump both together, deliberately, not as a drive-by edit.
- Missing precipitation renders as `N/A`, never `0.0 mm` — don't default it to zero.

## Testing conventions

- `tests/*.test.js` use `node --test` (no framework/deps). `tests/helpers.js` has shared fixtures.
- Tests target `js/core/*` almost exclusively; UI (`js/app.js`, `js/notifications.js`) is lightly covered.
- No browser test runner is set up — UI changes need manual verification via
  the `weather-helper-static` launch config (`.claude/launch.json`,
  `python -m http.server 4173`) in the Browser pane, not a headless test.

## CI

`.github/workflows/android.yml` runs `npm ci && npm test`, builds web +
Android debug APK, and publishes a GitHub Release APK on pushes to `main`,
`capacitor-android-port`, and `v*` tags. Mirror this locally before pushing
release-affecting changes: `npm test` then `npm run android:debug`.
